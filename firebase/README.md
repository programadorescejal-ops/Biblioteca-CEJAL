# 📚 Biblioteca CEJAL

Sistema de Biblioteca Escolar com Firebase

## 🚀 Funcionalidades

- 🔐 Autenticação com matrícula
- 📖 Catálogo de livros em tempo real
- 📚 Empréstimo e devolução de livros (máx 3)
- 👤 Perfil do aluno com histórico
- 📊 Painel administrativo
- 🏆 Sistema de gamificação com badges
- 🔔 Notificações em tempo real
- 📱 Design responsivo (mobile-first)

## 🛠️ Tecnologias

- HTML5 + CSS3 + JavaScript
- Firebase (Auth + Firestore + Hosting)
- Google Books API
- Font Awesome + Google Fonts
